# Ejecutar el Langing Page

Entrar a la carpeta: 

```sh
$ cd tradinn/
```

Construir el frontend:

```sh
$ cd frontend/
$ npm run build
```


Levantar los contenedores: 

```sh
$ docker compose up -d
```

Desde un navegador acceder a: 

```
http://localhost:8080/
```

Para detener los contenedores: 

```sh
$ docker compose down
```
