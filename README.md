# Tradinn (Actualizado hasta el 14/06)

Stack: 
- Frontend: React + Vite
- Backend: Express + JW
- DB: PostgresSQL
- Proxy inverso: Nginx
- Build: Docker 

## Para ejecutar:

1. Construir y levantar
```docker compose up --build```

2. Abrir en el navegador
```http://localhost:3001```

3. Para detener
```docker compose down```
